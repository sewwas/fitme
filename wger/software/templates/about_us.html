Staff PC & Desktop Application Deployment Guide

Comprehensive operational guide for gym reception staff, coaches, and administrators to configure, install, and run Fit Me OS on the front desk PC as a standalone desktop application with turnstile biometric hardware integration.

1. Install Fit Me as a Native Desktop App on Windows PC

You can run the Fit Me Portal in Standalone Desktop Window Mode without browser tabs, toolbars, or address bars for a completely focused, zero-distraction kiosk experience.

1
Open Fit Me Portal in Google Chrome or Microsoft Edge On the Gym Reception PC, open Chrome or Edge and visit http://localhost:8000/user/login (or your gym's official cloud URL).
2
Click the "Install App" Icon in the Address Bar Look at the right side of your browser URL address bar: click the Install Fit Me icon (computer monitor with down arrow) or click the three dots menu (⋮) → Save and Share / Apps → "Install this site as an app".
3
Pin to Windows Taskbar & Desktop When prompted by Windows, check "Pin to taskbar" and "Create Desktop shortcut". Fit Me will now launch in its own dedicated high-performance desktop window!
4
Configure Automatic Morning Startup (Optional) Press Win + R, type shell:startup, and press Enter. Copy the Fit Me Desktop shortcut into this Startup folder. Every morning when the reception PC boots up, Fit Me will launch automatically.
Desktop Progressive Web App (PWA) manifest ready.

3. ZKTeco Turnstile Biometric Hardware Bridge Daemon

The desktop reception PC hosts the background sync bridge that connects the local ZKTeco SpeedFace biometric turnstile controller to the Fit Me cloud engine.

A
Local Biometric Hardware Specifications
  • Turnstile Controller LAN IP: 192.168.1.23
  • Local ZKBio CVAccess Server: http://localhost:8098/api
  • Verification Modes: Face ID & Optical Fingerprint (No manual keypad PINs).
B
Running the Daemon on Reception PC (PowerShell) Run this command from the repository folder to initiate background turnstile telemetry:
python scripts/zkbio_bridge_daemon.py
C
Offline Queue Resilience If the gym's fiber/internet connection drops temporarily, the daemon automatically buffers punch events inside a local SQLite database (zkbio_offline_punches.sqlite3). All records are safely pushed to the cloud once internet restores with zero lost punches!

4. 80mm Thermal Receipt Printer Setup

Fit Me includes built-in styling for standard 80mm (3-inch) POS thermal roll printers used at gym reception desks:

  • POS Sales Slip: Automatically formatted to 80mm width with gym header, item breakdown, and QR verification.
  • Staff Salary Advance Voucher: Direct 80mm printout with signature lines for cashier and recipient.
  • Thermal Printer Setting: In the browser print dialog (Ctrl + P), select your receipt printer, set Margins to None, and enable Background graphics.
